# task start

```
task start <N> <slug> [--long | --from long/<M>-…] [--worktree]
```

## Когда звать
Начать работу над задачей: ветка `task/<N>-<slug>` от `origin/dev`, статус In progress. Повторный запуск безопасен.

- `--long` — ветка `long/<N>-<slug>`; сразу отправляется в `origin`, чтобы от неё начинались части.
- `--from long/<M>-…` — ветка задачи начинается от long-ветки, а не от `dev` (маленький PR в long-ветку). Не сочетается с `--long`.
- `--worktree` — ветка в копии `.worktrees/<slug>`: основная папка не переключается и может быть грязной, файлы из `.worktreeinclude` копируются при создании. **Последняя строка вывода — путь копии.**

Ветка уже есть — команда переключается на неё и перематывает отставшую до `origin`. Исследование — ветка не нужна, команда печатает «#<N> — исследование: ветка не нужна» и переводит задачу в In progress.

## Что проверяет
1. Аргументы: номер задачи и `<slug>`; `--from` указывает на long-ветку. Иначе сбой (код 2) со строкой использования.
2. Без `--worktree` — рабочая папка чистая.
3. Задача ровно на одной доске.
4. Задача открыта.
5. Задача не эпик.
6. Статус Groomed или In progress.
7. Нет открытых блокеров.
8. Исследование — без `--worktree`.
9. Папка и ветка: ветка не открыта в другой копии; `.worktrees/<slug>` свободна или это своя чистая копия; локальная ветка не разошлась с `origin`; для `--from` long-ветка есть в `origin`.

## Отказы
Код выхода 1. Текст — как печатает `task`, с подстановками `<N>`, `<ветка>`, `<папка>`.

| Текст | Причина | Что делать |
|-------|---------|------------|
| `в рабочей папке незакоммиченные изменения — закоммитьте или уберите их` | `git status` не пуст | — |
| `#<N> закрыта` | задача закрыта | переоткрыть задачу или взять другую |
| `#<N> — эпик: в работу берутся его подзадачи` | тип задачи — эпик | `task start` с номером подзадачи |
| `#<N> в статусе «<статус>» — сначала груминг` | статус не Groomed и не In progress | груминг (`/groom <N>`), затем `task groomed <N>` |
| `#<N> заблокирована: #<M>, … открыты` | открыты задачи-блокеры | сначала закрыть блокеры |
| `#<N> не на доске — добавьте её на доску проекта` | задачи нет на доске | — |
| `#<N> на нескольких досках` | задача на двух и более досках | убрать задачу со всех досок, кроме доски репозитория |
| `#<N> — исследование: ветка и копия не нужны` | исследование с `--worktree` | без `--worktree` |
| `папка <копия> занята — работайте там или удалите её` | `.worktrees/<slug>` есть, но не копия этой ветки: не зарегистрирована как копия, в ней есть правки или ветки ещё нет | — |
| `локальная <ветка> расходится с origin/<ветка> — сведите вручную` | локальная и удалённая ветки разошлись | `git -C <папка> log <ветка>...origin/<ветка>` — что разошлось; слить или пересоздать ветку |
| `нет ветки origin/<long-ветка> — сначала task start <N> <slug> --long` | `--from` указывает на несуществующую long-ветку | — |
| `ветка <ветка> открыта в <папка> — работайте там` | ветка открыта в другой копии | — |
