# task final

```
task final <N> --title «…» --body-file <файл> [--check «команда»]…
```

## Когда звать
Когда все блоки long-задачи слиты в `long/<N>-…`. Команда собирает итоговый PR `task/<N>-final` → `dev` с `Closes #<N>` — сразу к ревью, не черновиком. Звать из `long/<N>-…` или из `task/<N>-final`.

- Ветка `task/<N>-final` создаётся от `origin/long/<N>-…`; план задачи на ней убирается (копия остаётся в `plans/done/` основной папки).
- В long-ветку ничего не пушится.
- Повтор: в существующую `task/<N>-final` вливается свежая long-ветка, PR обновляется.
- Задача переводится в In review; команда печатает «#<N> → In review».
- `--title`, `--body-file` — заголовок и тело PR по шаблону; `--check «команда»` — команда проверки до публикации, можно несколько.

## Что проверяет
1. Первый аргумент — номер задачи (иначе сбой, код 2).
2. Текущая ветка — `long/<N>-…` этой задачи или `task/<N>-final`; из `task/<N>-final` long-ветка ищется по номеру задачи.
3. Рабочая папка чистая.
4. Ветка `task/<N>-final` готова: новая от `origin/long/<N>-…` или существующая с влитой свежей long-веткой.
5. Рабочая папка снова чистая (перед публикацией).
6. Каждая `--check` проходит.
7. У `task/<N>-final` нет уже слитого PR.
8. Задача ровно на одной доске.

## Отказы
Код выхода 1. Текст — как печатает `task`, с подстановками `<N>`, `<ветка>`, `<папка>`.

| Текст | Причина | Что делать |
|-------|---------|------------|
| `в рабочей папке незакоммиченные изменения — закоммитьте или уберите их` | `git status` не пуст | — |
| `у задачи #<N> нет long-ветки — итоговый PR не из чего собрать` | из `task/<N>-final` не найдена `origin/long/<N>-…` | задача из одного PR — `task pr` |
| `task final <N> запускается из long/<N>-… или task/<N>-final, сейчас «<ветка>»` | команда вызвана из другой ветки | `task start <N> <slug> --long`, затем повторить |
| `слияние <long-ветка> в task/<N>-final не прошло — разрешите конфликт и закоммитьте или проверьте, что <long-ветка> существует; затем повторите task final <N>` | конфликт слияния | `git status` — файлы с конфликтом |
| `PR #<P> уже слит — task done` | итоговый PR уже слит | — |
| `проверка «<команда>» не прошла — исправьте: <хвост вывода>` | команда `--check` вернула не 0 | запустить команду вручную — полный вывод |
| `#<N> не на доске — добавьте её на доску проекта` | задачи нет на доске | — |
| `#<N> на нескольких досках` | задача на двух и более досках | убрать со всех досок, кроме доски репозитория |
