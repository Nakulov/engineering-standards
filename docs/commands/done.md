# task done

```
task done
```

## Когда звать
После слияния PR задачи, из её ветки `task/<N>-<slug>` или `long/<N>-<slug>`. Команда обновляет `dev`, удаляет локальную ветку и переводит задачу в Done. Аргументов нет — с аргументами сбой (код 2).

- Из основной папки: `dev` обновляется до `origin/dev`.
- Из копии ворктри: копия отсоединяется на `origin/dev`, `dev` не трогается. Своя копия `.worktrees/<slug>` удаляется последним шагом — после этого текущей папки нет. Копия long-ветки, где слита ветка блока, остаётся.
- Из `task/<N>-final`: удаляется и long-ветка задачи — локально и в `origin`. Нет long-ветки — команда пишет об этом, удаляется только ветка итогового PR.
- Статус Done — только если задача уже закрыта (PR с `Closes`). Задача ещё открыта (PR с `Part of`) — команда печатает «#<N> открыта — не последний PR задачи, статус остаётся».

## Что проверяет
1. Нет аргументов (иначе сбой, код 2).
2. Текущая ветка — `task/<N>-…` или `long/<N>-…`.
3. Рабочая папка чистая.
4. У ветки есть PR.
5. PR слит.
6. Из `task/<N>-final`: long-ветка задачи не открыта в другой папке — проверяется до удаления, чтобы `task done` можно было повторить.
7. Если задача закрыта: она ровно на одной доске.

## Отказы
Код выхода 1. Текст — как печатает `task`, с подстановками `<N>`, `<ветка>`, `<папка>`.

| Текст | Причина | Что делать |
|-------|---------|------------|
| `<ветка> — не ветка задачи: task done запускается из task/<N>-… или long/<N>-…` | текущая ветка не ветка задачи; на отсоединённом `HEAD` вместо `<ветка>` печатается «HEAD отсоединён» | переключиться на ветку слитого PR |
| `в рабочей папке незакоммиченные изменения — закоммитьте или уберите их` | `git status` не пуст | — |
| `у ветки <ветка> нет PR — сначала task pr` | у ветки нет PR | — |
| `PR #<P> не слит — сначала слияние` | PR открыт | слить PR на GitHub |
| `ветка <ветка> открыта в <папка> — переключите там ветку и повторите task done` | из `task/<N>-final`: long-ветка задачи открыта в другой копии; `<ветка>` — long-ветка | — |
| `#<N> не на доске — добавьте её на доску проекта` | задача закрыта, но её нет на доске | — |
| `#<N> на нескольких досках` | задача закрыта и стоит на двух и более досках | убрать со всех досок, кроме доски репозитория |
