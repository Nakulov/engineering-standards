# task pr

```
task pr --title «…» --body-file <файл> [--check «команда»]… [--part] | --ready
```

## Когда звать
Открыть черновик PR по шаблону из ветки `task/<N>-<slug>`. Повторный запуск обновляет существующий PR: заголовок и тело.

- `--title «…»` — заголовок PR.
- `--body-file <файл>` — файл с текстом PR по шаблону; нет файла — сбой (код 2).
- `--check «команда»` — команда проверки, запускается через `sh -c` до публикации; можно несколько. Не прошла — PR не открывается.
- `--part` — PR не закрывает задачу: в тело вместо `Closes #<N>` попадает `Part of #<N>`. Так же всегда, если ветка задачи начата от long-ветки (`--from`).
- `--ready` — перевести черновик в ревью; других опций с ним нет. Если PR закрывает задачу (`Closes`), задача уходит в In review; при `Part of` статус остаётся, команда печатает «#<N> — PR не последний (Part of), статус остаётся».

База PR — `dev`; для ветки, начатой от long-ветки, — эта long-ветка.

PR в `dev` с `Closes`: план из `plans/<slug>.md` копируется в `plans/done/` основной папки и убирается из ветки коммитом «Убрать план: <название>», чтобы не попасть в `dev`. PR в long-ветку или с `--part` план не трогает.

## Что проверяет
1. Текущая ветка — `task/<N>-<slug>`, не `long/…`.
2. Без `--ready`: рабочая папка чистая.
3. Без `--ready`: аргументы — `--title`, `--body-file`, `--check`; иначе сбой (код 2) со строкой использования.
4. Без `--ready`: PR в `dev` с `Closes` — план убирается из ветки (см. выше).
5. Без `--ready`: каждая `--check` проходит, по порядку.
6. Без `--ready`: ветка отправляется в `origin`, PR ветки ещё не слит.
7. С `--ready`: у ветки есть PR, он не слит, задача ровно на одной доске (если PR закрывает задачу).

## Отказы
Код выхода 1. Текст — как печатает `task`, с подстановками `<N>`, `<ветка>`, `<папка>`.

| Текст | Причина | Что делать |
|-------|---------|------------|
| `«<ветка>» — не ветка задачи: task pr запускается из task/<N>-…` | текущая ветка не `task/<N>-<slug>` | `task start <N> <slug>` или переключиться на ветку задачи |
| `из long-ветки PR в dev открывает task final <N>` | текущая ветка — `long/<N>-…` | — |
| `у ветки <ветка> нет PR — сначала task pr --title … --body-file …` | `--ready` без открытого PR | — |
| `PR #<P> уже слит — task done` | PR ветки уже слит (при `--ready` и при публикации) | — |
| `в рабочей папке незакоммиченные изменения — закоммитьте или уберите их` | `git status` не пуст | — |
| `проверка «<команда>» не прошла — исправьте: <хвост вывода>` | команда `--check` вернула не 0 | запустить команду вручную — полный вывод |
| `#<N> не на доске — добавьте её на доску проекта` | `--ready`: задачи нет на доске | — |
| `#<N> на нескольких досках` | `--ready`: задача на двух и более досках | убрать со всех досок, кроме доски репозитория |
