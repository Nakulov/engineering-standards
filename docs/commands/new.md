# task new

```
task new <тип> --title «…» --body-file <файл> [--parent N] [--blocked-by N,N]
```

## Когда звать
Завести задачу по шаблону типа: тело — из `--body-file`, метка типа — из шаблона `.github/ISSUE_TEMPLATE/<тип>.md`, задача попадает на доску репозитория в Backlog. Типы — шаблоны в `.github/ISSUE_TEMPLATE/`: `bug`, `epic`, `research`, `task`. Что заводить, решают в разговоре — команда только создаёт решённое.

- `--title` — заголовок задачи.
- `--body-file` — файл с телом задачи по шаблону типа.
- `--parent N` — сделать задачу подзадачей `#N`.
- `--blocked-by N,N` — задачи-блокеры, номера через запятую.

Вывод: «#<N> создана: <метка>» (и «, подзадача #<P>»), затем «#<N> → Backlog».

## Что проверяет
1. Тип задан; `--title` и `--body-file` заданы. Иначе сбой (код 2) со строкой использования.
2. `--parent` и `--blocked-by` — номера задач. Иначе сбой (код 2).
3. Есть шаблон `.github/ISSUE_TEMPLATE/<тип>.md` с меткой типа. Иначе сбой (код 2) со списком типов.
4. Файл `--body-file` читается. Иначе сбой (код 2).
5. Задача создаётся, со связями «подзадача» и «blocked by».
6. Задача добавляется на доску: у репозитория ровно одна связанная доска, задача ровно на одной доске и видна в списке доски.
7. Статус — Backlog; если автодобавление поставило другой, команда переводит.

## Отказы
Код выхода 1. Текст — как печатает `task`, с подстановками `<N>`, `<ветка>`, `<папка>`.

| Текст | Причина | Что делать |
|-------|---------|------------|
| `у репозитория нет связанной доски — свяжите с репозиторием одну доску` | у репозитория нет доски | GitHub → Projects → связать доску с репозиторием |
| `у репозитория несколько связанных досок — свяжите с репозиторием одну доску` | связано больше одной доски | отвязать лишние |
| `#<N> не на доске — добавьте её на доску проекта` | задача создана, но добавление на доску не прошло | добавить созданную задачу на доску вручную |
| `#<N> на нескольких досках` | новая задача попала на несколько досок | убрать со всех досок, кроме доски репозитория |
