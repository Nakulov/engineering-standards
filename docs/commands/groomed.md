# task groomed

```
task groomed <N>
```

## Когда звать
Груминг закончен: задача `#<N>` переводится из Backlog в Groomed, после чего её берёт `task start`. Если задача уже в другом статусе, статус не меняется, команда печатает «#<N> уже в «<статус>»». Переход печатается как «#<N> → Groomed».

## Что проверяет
1. Задан ровно один номер задачи. Иначе сбой (код 2) со строкой использования.
2. Задача открыта.
3. Тип задачи не эпик.
4. Задача есть ровно на одной доске.

## Отказы
Код выхода 1. Текст — как печатает `task`, с подстановками `<N>`, `<ветка>`, `<папка>`.

| Текст | Причина | Что делать |
|-------|---------|------------|
| `#<N> закрыта` | задача закрыта | — |
| `#<N> — эпик: в Groomed переводятся его подзадачи` | тип — эпик | `task groomed` с номером подзадачи |
| `#<N> не на доске — добавьте её на доску проекта` | задачи нет на доске | — |
| `#<N> на нескольких досках` | задача на двух и более досках | убрать со всех досок, кроме доски репозитория |
