# task stage

```
task stage create --title «…» --body-file <файл> [--due ГГГГ-ММ-ДД]
```

## Когда звать
Завести веху этапа: описание берётся из `--body-file` и должно соответствовать шаблону `templates/github/stage.md` плагина. Команда создаёт веху в репозитории и печатает «этап «<название>»: <ссылка>».

- `--title` — название вехи.
- `--body-file` — файл с описанием по шаблону этапа; пустой раздел шаблона заполняется словом «Нет».
- `--due` — срок вехи в формате `ГГГГ-ММ-ДД`; без опции срока нет.

### Подкоманды
- `create` — создать веху.

## Что проверяет
1. Первый аргумент — `create`; `--title` и `--body-file` заданы. Иначе сбой (код 2) со строкой использования.
2. `--due`, если задан, — в формате `ГГГГ-ММ-ДД`. Иначе сбой (код 2).
3. Файл `--body-file` читается. Иначе сбой (код 2).
4. В описании нет пустых разделов шаблона этапа.

## Отказы
Код выхода 1. Текст — как печатает `task`, с подстановками `<N>`, `<ветка>`, `<папка>`.
