# task commit

```
task commit --message-file <файл>
```

## Когда звать
Закоммитить задачу плана по шаблону: файлы для коммита берутся из раздела «Файлы:» сообщения. Формат сообщения:

```
<первая строка — что сделано>

Задача плана: <заголовок задачи плана>   ← обязательна, если в ветке есть план plans/<slug>.md

Файлы:
- `путь` — что изменено
```

В коммит идут файлы из «Файлов» и изменённые планы `plans/*.md`. Команда печатает «коммит: <первая строка>».

- `--message-file` — файл с сообщением; относительный путь считается от папки, заданной `-C`.

## Что проверяет
1. Заданы ровно `--message-file <файл>`. Иначе сбой (код 2) со строкой использования.
2. Файл сообщения существует. Иначе сбой (код 2).
3. Первая строка сообщения не пуста.
4. Если в ветке есть план `plans/<slug>.md` (добавлен относительно `origin/dev`), в сообщении есть строка «Задача плана: …».
5. В разделе «Файлы:» есть хотя бы одна строка вида «- `путь` — что изменено».
6. Каждый путь из «Файлов» изменён (и существует).

## Отказы
Код выхода 1. Текст — как печатает `task`, с подстановками `<N>`, `<ветка>`, `<папка>`.

| Текст | Причина | Что делать |
|-------|---------|------------|
| `первая строка сообщения пуста — напишите, что сделано` | файл сообщения начинается пустой строкой | — |
| ``в ветке план `<план>` — нет строки «Задача плана: …», добавьте заголовок задачи плана`` | в ветке есть план, а в сообщении нет строки задачи плана | — |
| ``раздел «Файлы:» пуст — перечислите файлы строками «- `путь` — что изменено»`` | нет раздела или в нём нет строк | — |
| `` `<путь>` не изменён или не существует — уберите из «Файлов» `` | путь из «Файлов» не изменён | `git status` — что изменено |
