# Тесты Kotlin

Правила тестов на Kotlin для всех наших проектов. Читают:
- человек — когда пишет тесты и проводит ревью;
- агент, который пишет код, — перед правкой файлов в `src/test/`;
- агенты ревью — когда проверяют тесты.

Тесты — тоже код: к ним применяется и кодстайл Kotlin (`docs/code-style/kotlin/`). Правило тестов, которое ему противоречит, называет исключение явно.

## Файлы

| Префикс ID | Файл | О чём |
|------------|------|-------|
| `KT-KIT` | [kotest-kit.md](kotest-kit.md) | формы тестов Kotest и KotestKit: спека, моки, проверки вызовов, параметры, результат, исключение, JSON |
| `KT-TEST` | [organization.md](organization.md) | организация тестов: спека по файлу, тестовые данные, без логики в тестах |
