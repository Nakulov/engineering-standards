# Банк знаний

Стандарты наших проектов: стиль кода, тесты, команды процесса. Это оглавление — единственный вход в банк для скиллов и агентов: найди строку своей работы и прочитай целиком все её файлы; другие строки не читай.

## Что читать

| ID | Делаешь | Читай |
|----|---------|-------|
| BANK-1 | пишешь или правишь код Kotlin (`*.kt`, `*.kts`) — в плане или в файлах | [code-style/kotlin/README.md](code-style/kotlin/README.md), затем файлы из его таблицы |
| BANK-2 | пишешь или правишь тест Kotlin (`src/test/`) | BANK-1 и ещё [testing/kotlin/README.md](testing/kotlin/README.md) |
| BANK-3 | переносишь в файлы готовый код из плана | ничего: код плана уже по стандарту. BANK-1 и BANK-2 — только когда пишешь код не из плана: чинишь упавший тест или сборку |
| BANK-4 | проверяешь дифф | BANK-1, BANK-2 — по видам изменённых файлов |
| BANK-5 | запускаешь `task <команда>` или `setup` | файл команды — из таблицы [commands/README.md](commands/README.md) |

Строки для твоей работы нет — банка для неё нет: работай по образцам существующего кода, правил не придумывай.

## Новый раздел

Раздел банка — папка `docs/<область>/<язык>/` со своим `README.md`. Добавил раздел — добавь строку в «Что читать» со следующим ID: без неё раздел никто не прочитает. ID не переиспользуются. Раздел без строки ловит тест `BankIndexSpec`.
