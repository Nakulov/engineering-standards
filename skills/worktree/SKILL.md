# Ворктри

Создаёт изолированную копию целевого репозитория на ветке задачи и выводит её путь; сессия остаётся в основной папке. Самостоятельный скилл: вызывает пользователь перед работой или `execute` при ответе «Ворктри».

## Где лежит копия

`.worktrees/<slug>` внутри репозитория.
- Даёт: правку файлов в копии без запросов разрешения — `.claude/` защищён, правила `allow` запись в него не открывают; легко найти и убрать.
- Требует: строку в `.gitignore`; исключить папку в Android Studio — иначе двойной поиск и индексация.

## Шаги

Вход — `<N> <slug>` и `--long` для long-ветки.
1. `task start <N> <slug> [--long] --worktree` — копия `.worktrees/<slug>` основной папки на ветке задачи; основная папка не переключается; файлы из `.worktreeinclude` копируются. Последняя строка вывода — путь копии. Ветка открыта в другой папке — команда откажет с путём: сообщи и предложи перейти туда; сам не чини.
2. Выведи путь копии из шага 1: `Копия: <путь>`. Скилл вызвал пользователь, не `execute`, — добавь строку «Выполнение плана в копии — `/execute <N> <slug>` из основной папки; сессию в копии не открывай». Сессию в копию не переводи — `EnterWorktree` не вызывай: сессия в копии не может писать вне неё, а журнал `execute` и `plans/done/` лежат в основной папке.
3. После слияния последнего PR задачи — из основной папки `task -C <основная папка>/.worktrees/<slug> done`. Команда удаляет копию последним шагом. Каждый этап — новая сессия из основной папки.
