# Ворктри

Создаёт изолированную копию целевого репозитория на ветке задачи и переводит в неё сессию. Самостоятельный скилл: вызывает пользователь перед работой или `execute` при ответе «Ворктри».

## Где лежит копия

`.worktrees/<slug>` внутри репозитория.
- Даёт: правку файлов в копии без запросов разрешения — `.claude/` защищён, правила `allow` запись в него не открывают (#93); легко найти и убрать.
- Цена: `EnterWorktree` в копию вне `.claude/worktrees/` спрашивает разрешение — один раз на вход.
- Требует: строку в `.gitignore`; исключить папку в Android Studio — иначе двойной поиск и индексация.

## Шаги

Вход — `<N> <slug>` и `--long` для long-ветки.
1. `task start <N> <slug> [--long] --worktree` — копия `.worktrees/<slug>` основной папки на ветке задачи; основная папка не переключается; файлы из `.worktreeinclude` копируются. Последняя строка вывода — путь копии. Ветка открыта в другой папке — команда откажет с путём: сообщи и предложи перейти туда; сам не чини.
2. Сессия переходит в копию — `EnterWorktree` с `path` = путь из шага 1.
3. После слияния последнего PR задачи — `task done` из копии: `cd .worktrees/<slug> && scripts/task done`. Команда удаляет копию последним шагом. Выходить из копии сессией (`ExitWorktree`) не нужно: каждый этап — новая сессия из основной папки.
