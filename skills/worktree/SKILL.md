# Ворктри

Создаёт изолированную копию целевого репозитория на ветке задачи и переводит в неё сессию. Самостоятельный скилл: вызывает пользователь перед работой или `execute` при ответе «Ворктри».

## Где лежит копия

`.claude/worktrees/<slug>` внутри репозитория.
- Даёт: переключение между копиями в одной сессии (`EnterWorktree` с `path` из копии переходит только в копии внутри `.claude/worktrees/`); одно место со своими копиями Claude Code; легко найти и убрать.
- Требует: строку в `.gitignore`; исключить папку в Android Studio — иначе двойной поиск и индексация.

## Шаги

Вход — `<N> <slug>` и `--long` для long-ветки.
1. `task start <N> <slug> [--long] --worktree` — копия `.claude/worktrees/<slug>` основной папки на ветке задачи; основная папка не переключается; файлы из `.worktreeinclude` копируются. Последняя строка вывода — путь копии. Ветка открыта в другой папке — команда откажет с путём: сообщи и предложи перейти туда; сам не чини.
2. Сессия переходит в копию — `EnterWorktree` с `path` = путь из шага 1.
3. После слияния последнего PR задачи — `task done` из копии: `cd .claude/worktrees/<slug> && scripts/task done`. Команда удаляет копию последним шагом. Выходить из копии сессией (`ExitWorktree`) не нужно: каждый этап — новая сессия из основной папки.
