# Ревью и стандарты

Читает скилл `execute` на шаге 5 — только в запуске последнего блока, цикл не остановлен. Агенты ревью и стандартов — только чтение, ничего не правят. Их находки сводишь только механически: не проверяешь, не оцениваешь, не выбрасываешь; кода для этого не читаешь.

## 1. Запуск

Запусти параллельно, по имени, без истории сессии — только этих:
- `implementation-reviewer` — реализация: изменения достигают цели плана; сделано то, что в плане, и ничего сверх;
- `test-reviewer` — тестирование: тесты проверяют поведение, крайние случаи покрыты;
- `standards-reviewer` — стандарты: банк знаний — стандарты наших проектов, отдельно от общего ревью.

Каждому: путь к плану, рабочая папка, база — `git -C <рабочая папка> merge-base origin/dev HEAD` (начало ветки плана; одинаково для одного блока и нескольких); `implementation-reviewer` и `test-reviewer` — ещё журнал.

Дождись всех. Агент упал или ответил не по шаблону — не перезапускай: в итоге «<зона>: не выполнено — <ответ агента>»; ревью цикл и PR не блокирует.

## 2. Сведение

Номера находкам ставишь ты — агенты отвечают без номеров.
- **Ревью** (реализация, тестирование): одинаковые `файл:строка` и проблема — одна находка, зоны через запятую, оценка — более высокая (К выше В, В выше М). Номера — К1, В1, М1…
- **Стандарты**: номера — СК1, СВ1, СМ1…; находка с теми же `файл:строка` и проблемой, что в ревью, — не повторяй: «= ревью К1».

Сводка для журнала (шаг 6 скилла) — по шаблону:
```
К1. `файл:строка` — <проблема> (<зоны>)
    Влияет: <на что и чем грозит>
    Исправить: <как — одним предложением, без кода>
    Вопрос: <зона: номер и название> | Правило: <как у агента стандартов>
```

Находки пока не исправляем — собираем в журнал для анализа.

## 3. Итог

Сообщи — только первая строка каждой находки; сначала ревью, потом стандарты:
```
Ревью: замечаний нет. Проверено: <зоны>.
```
```
Ревью: <N> находок — критичных <К>, важных <В>, минорных <М>.
К1. `файл:строка` — <суть> (<зона>)
В1. …
Полный список — <журнал>.
```
```
Стандарты: замечаний нет.
```
```
Стандарты: банк знаний не найден — проверено только по образцам существующего кода.
```
```
Стандарты: <N> находок — критичных <К>, важных <В>, минорных <М>.
СК1. `файл:строка` — <суть>
СВ1. …
Полный список — <журнал>.
```
