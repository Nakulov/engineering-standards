# engineering-standards

Общие инженерные стандарты для всех наших проектов: процесс работы, правила кода, шаблоны нового репозитория и плагин
Claude Code, который их доставляет.

## Цель

Репозиторий задаёт общие правила, которые соблюдаются в любом нашем проекте, и даёт область гибкости под особенности
конкретного проекта.

Без него правила живут внутри одного проекта, и в каждом новом проекте их проходят заново: настраивают репозиторий и
доску, копируют и адаптируют скиллы, заново объясняют ассистенту кодстайл, правила коммитов и структуру проекта.

## Для кого

- **Люди** — читают стандарты и работают по ним.
- **Claude** — получает правила и скиллы через плагин и следует им в каждой сессии.

## Состав

- **Процесс:** workflow и скиллы, в том числе оркестратор, который ведёт сессию от груминга до выполнения задачи.
- **Новый репозиторий:** настройки (защита основной ветки и прочее), доска и работа с ней, шаблоны задач и PR,
  заготовки workflow, roadmap и README.
- **Правила кода по языкам** — Kotlin, JSON, Python: кодстайл, гайдлайны, структура проекта (пакеты, имена классов).
- **Правила коммитов.**
- **Конфиги линтеров.**
- **Плагин Claude Code**, через который всё это доставляется в проекты.

## Границы

Особенностей конкретных проектов здесь нет. Они лежат в самих проектах.

## Общее и проектное

- Общие правила и скиллы лежат в плагине.
- Особенности проекта лежат в файлах проекта по договорённым путям.
- Файл проекта может только **дополнять и сужать** общие правила. Отменять их нельзя.

## Подключение

Проект подключает плагин Claude Code из этого репозитория. Правила не копируются в проект, поэтому изменения стандартов
доходят до всех проектов без ручной синхронизации.

## Изменение стандартов

Стандарты меняются только задачей в этом репозитории: issue → ветка → PR. В целевых проектах общие правила не правятся.
Если правило мешает в проекте, заведите задачу здесь.

## Язык

Основной язык — русский: README, документы, задачи, коммиты и PR. Английский — только в названиях веток.

Репозиторий публичный: примеры только абстрактные, без названий продуктов.
